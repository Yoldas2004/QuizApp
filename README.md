# QuizApp

A simple quiz application built with C# as a console program.  
This project was created to practice basic C# programming concepts.

## Features

- Displays quiz questions in the console
- Multiple choice answers
- User input handling
- Structured using classes

## Technologies

- C#
- .NET
- Console Application

## Project Structure

QuizApp
│
├── Program.cs
├── Quiz.cs
└── Questions.cs

## Purpose

This project was built to practice C# and understand fundamental programming concepts such as:

- Classes
- Methods
- Arrays
- Console input and output
